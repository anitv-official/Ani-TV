# AniTV

تطبيق Flutter لمشاهدة الأنمي وقراءة القصص المصورة، مخصص لنظام Android فقط.

## الهوية
- اسم التطبيق: AniTV
- معرف الحزمة: `com.anitv.app`
- اللغة الافتراضية: العربية مع اتجاه RTL

## البناء
يتم البناء حصريًا عبر GitHub Actions باستخدام ملف `.github/workflows/android.yml`. لا يتطلب المشروع بناءً محليًا.
